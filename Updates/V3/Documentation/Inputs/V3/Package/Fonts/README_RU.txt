ШРИФТ: MONTSERRAT

В макетах Figma проверены начертания Regular (400) и Bold (700).
Источник: https://github.com/google/fonts/tree/main/ofl/montserrat
Страница семейства: https://fonts.google.com/specimen/Montserrat

Файлы шрифта не включены: официальный источник не удалось скачать в этой сессии.
Перед сборкой получить Montserrat из официального источника вместе с OFL.txt.
Для Unity подготовить Regular и Bold и текстовые ресурсы проекта с кириллицей, латиницей,
цифрами, тире, знаком +, /, %, символом &. Не заменять шрифт системным без сверки.
Если Unity-проект не принимает переменный TTF, использовать статические экземпляры весов 400 и 700.
