# Cascade V4

Новая версия Cascade: мобильная музыкальная головоломка в Unity, написанная с нуля под 2D-дизайн.
Старый проект в `Updates/V3` остаётся только справочником.

## Как открыть

1. Unity Hub → Add → папка `Updates/V4`. Версия редактора: **6000.6.8f1**.
2. Открыть любую сцену (например `Assets/Scenes/SampleScene.unity`) и нажать Play.
   Игра запускается сама: `CascadeApp` создаётся через `RuntimeInitializeOnLoadMethod`, отдельная сцена не нужна.
3. Окно Game: добавить размер 1080 × 1920 (портрет).

Весь интерфейс собирается кодом на uGUI, префабов и ссылок в сценах нет.

## Где что лежит

| Папка | Что внутри |
|---|---|
| `Assets/Cascade/Core` | Правила игры без UnityEngine: поле 6×6, каскады, генератор сфер, ритм, очки, победа и поражение |
| `Assets/Cascade/Tests/Editor` | Тесты правил (Window → General → Test Runner → EditMode) |
| `Assets/Cascade/Scripts/App` | Запуск приложения и переключение экранов |
| `Assets/Cascade/Scripts/Audio` | Музыкальные часы (`Conductor`) и вибрация |
| `Assets/Cascade/Scripts/Data` | Список миров и уровней, сохранения, тексты на двух языках, чтение карт ритма |
| `Assets/Cascade/Scripts/UI` | Экраны: меню, карта мира, игра, настройки |
| `Assets/Cascade/Resources` | Спрайты, шрифты, музыка (OGG) и карты ритма (JSON) |
| `Assets/Cascade/Editor` | Настройки импорта, меню Cascade, мост редактора |

## Где менять баланс

- `Core/BalanceConfig.cs`: очки, множитель, окна PERFECT и GOOD, вероятность фиолетовой сферы,
  стартовые сферы, автосфера после хода, бездействие, энергия, монеты.
- `Scripts/Data/LevelCatalog.cs`: миры, уровни и цель по очкам (очки в секунду от первого уровня к последнему).
- `Resources/BeatMaps/<id>.json`: карта ритма трека. `times` — секунды, `levels`: 0 сильная доля,
  1 четверть, 2 восьмая, 3 шестнадцатая.

Правила меняются только в `Core`, и каждое правило покрыто тестом. Экраны ничего не считают сами:
они показывают события хода, которые вернуло ядро.

## Синхронизация звука

`Conductor.SongTime` возвращает место в треке, которое игрок слышит сейчас: аудиочасы Unity (`dspTime`)
минус задержка вывода. Аудиобуфер при старте уменьшается до 256. Ручная поправка лежит в настройках игры
(«Синхрон звука»), там же включается подсказка «рано / поздно» в миллисекундах.

## Мост редактора (DevBridge)

`Assets/Cascade/Editor/DevBridge` — служебный инструмент разработки. Он пишет ошибки компиляции, журнал игры
и итоги тестов в папку `DevBridge` рядом с `Assets` и выполняет команды из `DevBridge/command.txt`
(refresh, play, stop, shot, call). В сборку игры не попадает, папка `DevBridge` в git не хранится.
