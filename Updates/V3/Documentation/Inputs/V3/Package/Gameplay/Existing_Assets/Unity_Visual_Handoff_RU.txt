CASCADE — передача перерисованной графики в Unity

Этот пакет задаёт внешний вид и размещение отдельных PNG. Он не содержит игровую сборку, 3D-модели, динамический HUD или готовые анимации. Существующий проект Cascade не изменялся.

Контроль композиции
1. Использовать холст 941×1672 и Layout_941x1672.json. Координаты начинаются в левом верхнем углу. Все размеры относятся ко всему PNG вместе с прозрачным запасом.
2. Отрисовывать layers_back_to_front в указанном порядке. Фон и пустое поле — отдельно; каждая из 15 сфер и следующая сфера — самостоятельный объект.
3. Для RectTransform с верхним левым anchor/pivot использовать anchoredPosition=(x, -y), sizeDelta=(width,height). Масштаб всей композиции менять равномерно. Положение в safe area телефона настроить отдельно; растягивать поле по одной оси нельзя.
4. Не обрезать прозрачные поля автоматически: у сфер разный внутренний размер. Координаты уже учитывают их индивидуальный масштаб и центр. Поле целиком начинается при x=-26.5 из-за прозрачного запаса; его видимая часть находится внутри экрана.
5. Матрица заполнения нужна только для визуального сравнения с исходным рисунком. Она не заменяет правила стартовой генерации из ТЗ.

Начальный профиль импорта для визуальной проверки
Texture Type: Sprite (2D and UI); Sprite Mode: Single; Mesh Type: Full Rect; sRGB: On; Alpha Source: Input Texture Alpha; Alpha is Transparency: On. Сохранять полный прямоугольник спрайта и его полупрозрачные ореолы. Для контрольного экрана использовать Bilinear, Clamp, без mipmaps и без потерь от сжатия; оптимизировать после сравнения на устройстве.

Названия и назначение настроек сверены с официальной документацией Unity:
https://docs.unity.com/en-us/engine/6000.0/manual/materials-and-shaders/textures/textures-reference/texture-type-sprite
Перечисленный профиль — предложенная настройка этого пакета, а не результат проверки в Unity Editor.

Границы готовности
• Все блики, грани, ноты и исходное свечение уже нарисованы внутри PNG. Не добавлять сильный bloom поверх при первом сравнении: он изменит внешний вид.
• Пустое поле содержит все 36 ячеек в одном изображении. Его можно двигать целиком. Отдельные ячейки ещё не выделены в самостоятельные спрайты.
• hud-overlay.png — статическая надпись и полоса для макета. Счёт, время, множитель, название трека и прогресс в игре должны обновляться отдельным интерфейсом. Не использовать этот слой как рабочий HUD.
• Мерцание каждой клетки, рост интенсивности серии и сброс при промахе нужно реализовать отдельными эффектами. Из PNG это поведение автоматически не появится.
• Это растровые изображения с объёмным видом. Они сохраняют выбранный ракурс; свободный поворот камеры и настоящая объёмная геометрия требуют отдельной 3D-работы.
• Перерисовка отличается от исходного концепта контурами нот, бликами, деталями кристаллов и силой свечения. Пиксельное совпадение не заявлено.

Проверка перед приёмкой
Собрать статический экран и сравнить с Cascade_Redrawn_Mockup.png при одинаковом размере. Проверить 6×6 клеток, центры/масштабы сфер, прозрачные края и отсутствие лишнего bloom. После этого проверить смену состояний, попадания в ритм и размещение внутри safe area на iPhone 17 Pro. В этом пакете таких запусков ещё не было.
