Актуальный каталог: Content_Catalog_v3.json. Content_Catalog_v2.json — байт-в-байт одинаковый совместимый псевдоним прежнего имени, НЕ старая привязка. Все source_audio_path относительно корня пакета. Исходники проверены по SHA256, соответствие жанрам — по двум скриншотам пользователя. Null-поля заполняются после реального импорта и проверки карт долей. Миграция описана в Content_Migration_v3.json, здесь она не выполнялась.
