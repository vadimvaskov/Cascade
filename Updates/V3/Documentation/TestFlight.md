# Cascade — кандидат TestFlight 1.0 (15)

**Подготовлен исходный проект для сборки на Mac. В Apple ещё не загружен.** Последний документированный опубликованный выпуск — [1.0 (14)](Revisions/TestFlight-1.0-14.md).

[Пошаговая сборка и загрузка на Mac](BUILD_ON_MAC.md). Проект: Updates/V3, Unity 6000.6.8f1, сцена Assets/Scenes/CascadeGame.unity. Bundle ID fitness.quokka.caskade и команда Quokka RUT46C38YA сохранены. Номер 15 — следующий после документированного 14; если уже занят в App Store Connect, передать следующий номер скрипту.

## Что изменилось

Новый главный экран и меню, выбор Ми/Фа, обновлённое игровое поле, вечерний 3D-мост с движущимся миром, анимированные персонажи, фонари, компактные стеклянные панели. Одна подвижная сфера перед героем; при постановке на поле объёмный поток идёт от неё к герою.

Свободные переходы между четвертями, восьмыми и шестнадцатыми; зрительный ритм для игры без музыки; постоянная пульсация света вокруг экрана и поля с постепенным усилением до ×10. Музыка, восемь треков по 1:30 и сохранения остаются в проекте.

## Проверки и границы

Windows Editor и player проверены. Логика ритма, каскады, сохранения, оба героя, ввод, пауза, навигация, разные пропорции экрана, объёмная энергия и ограниченные пулы эффектов — PASS. [Проверки источников](Release/source-checks.txt), [игровые проверки](IntegrationReview/companion-volume-play-checks.txt).

Экспорт iOS, компиляция Metal/IL2CPP, подпись, архив и доставка Apple должны быть выполнены на Mac. Проверка производительности и визуальная приёмка на физическом iPhone/iPad ещё нужны. Карты музыки остаются предварительными.
