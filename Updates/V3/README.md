# Cascade — музыкальный мир

Рабочий проект: **эта папка Updates/V3**. Unity **6000.6.8f1**. Подготовленный кандидат для iOS: **1.0 (15)**; это ещё не опубликованный выпуск.

## Запуск

Добавьте папку Updates/V3 в Unity Hub, дождитесь импорта и откройте **Assets/Scenes/CascadeGame.unity**, затем Play. Сцена уже собрана и включена в Build Settings. Пересоздавать её командами старого прототипа не нужно.

[Инструкция для Mac и TestFlight](Documentation/BUILD_ON_MAC.md) · [Статус выпуска](Documentation/TestFlight.md)

## Что входит

- Главное меню с музыкальным парящим городом, выбором Ми/Фа, пластинками, картой, коллекцией и ежедневными заданиями; компактные стеклянные меню.
- Живой вечерний мост, движущийся мир, оба анимированных героя, светящиеся фонари и отдельное освещение персонажа.
- Одна сфера перед героем: цвет и рисунок совпадают со следующей сферой. Она плавно ускользает вперёд и возвращается.
- Установка на поле запускает объёмный поток **от летящей сферы к герою**. Из ячеек энергия не вылетает.
- Поле 6×6, быстрые постановки и каскады, восемь тестовых пластинок с треками по 1:30.
- Свободные переходы между ¼, ⅛ и ¹⁄₁₆ без переключателя; зрительный индикатор работает и без музыки. Повтор одной доли не приносит повторную ритмическую награду.
- Множитель увеличивается каждые 3 попадания, ×10 с 27-го. Постоянная световая пульсация мира, периметра экрана и поля постепенно усиливается к ×10.
- Настройки музыки, звуков, вибрации, языка и мягких эффектов; сохранение прогресса и калибровки.

## Проверки

**Cascade → Approved game → Check rhythm and saves** — логика и данные. **Cascade → iOS → Check release sources** — комплектность релизной сцены и ресурсов, затем те же проверки. Последние отчёты: [Release/source-checks.txt](Documentation/Release/source-checks.txt), [проверка игрового режима](Documentation/IntegrationReview/companion-volume-play-checks.txt).

[История интеграции и художественных решений](Documentation/APPROVED_GAME_HANDOFF.md) содержит предыдущие итерации; более поздние записи заменяют ранние варианты.

Проверены Windows Editor и Windows player. Компиляцию Metal/IL2CPP, подпись и архивирование нужно выполнить на Mac. На физическом iPhone/iPad ещё проверить частоту кадров, нагрев, звук, вибрацию, Safe Area и яркость эффектов. Карты ритма сохраняют статус предварительных; автоматические проверки не заменяют слуховую приёмку.

Старые сцены CascadePrototype, Dreamworld и Sunset сохранены как исходные этапы. Для релиза используется только CascadeGame.unity.
