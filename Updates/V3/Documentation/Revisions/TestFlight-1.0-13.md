# Cascade — TestFlight 1.0 (13)

**Сборка загружена 8 ноября 2026 в 19:10:55 UTC / 23:10:55 Dubai, `EXPORT SUCCEEDED`. Apple обрабатывает пакет; доступность установки ещё не подтверждена.** Предыдущая опубликованная версия: [1.0 (12)](Revisions/TestFlight-1.0-12.md).

## Изменения

- Все 8 пластинок открыты для тестирования через обычное меню, включая существующие сохранения. Флаг `testing_unlock_all_records` не подменяет заработанный прогресс.
- Все 8 активных песен сокращены до **1:30**, последние 1 с — плавное затухание. Полные оригиналы сохранены. Каталог, длительности, хэши и карты соответствуют новой музыке.
- Исправлена ритмическая карта **Neon Overdrive / уровень 2**: прежняя сетка около 71 BPM заменена пульсом ударных около 105 BPM. Множитель по-прежнему ×1–×10, +1 за каждые 3 уникальных попадания подряд. Окно ±120 мс и калибровка сохранены.
- При свободном выборе последней пластинки результат не объявляет всю коллекцию пройденной без остальных побед.
- Сохранились иконка, компенсация задержки света, экран повтора/выхода, быстрые установки, каскады и временный бонус +2.

Результаты полных песен архивируются по прежним хэшам; рекорды коротких версий отдельные. Заработанные открытия и настройки сохранены.

Регрессии модели, 36 нативных касаний, HUD, бонуса, паузы, поражения и прогресса: PASS. **173 быстрых хода / 181 волна каскада** совпали с моделью. Все 3 старых и 8 новых аудиопар прошли проверку SHA-256 / длительности; первые 89 с новых файлов совпадают с прежним PCM.
