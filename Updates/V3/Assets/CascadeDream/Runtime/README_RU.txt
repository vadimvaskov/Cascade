ЧТО В СЦЕНЕ
Ми из утверждённой модели Rodin, Humanoid-скелет и цикл бега.
Одна музыкальная сфера перед героем. Она не размножается по дороге.
Мост из восьми повторяемых участков, мягко скруглённая брусчатка,
изогнутые фонари, цветущие деревья с плавными ветвями, парящие острова,
струящиеся водопады, музыкальные павильоны и дома с округлыми крышами.
Дальний план движется медленнее ближнего. Скорость нарастает плавно.
Камера по умолчанию неподвижна; лёгкое покачивание можно включить.

УПРАВЛЕНИЕ ПРОСМОТРОМ
Пробел / Escape — пауза; R — начать заново.
Скорость и интенсивность движения: компонент DreamRunWorld на корневом объекте.

ПЕРЕНОС В ИГРУ
1. Нужен Unity 6000.6.8f1 с Universal Render Pipeline 17.6.0 либо совместимая версия.
2. Assets → Import Package → Custom Package → Cascade-Mi-Dreamworld.unitypackage.
3. Открыть Assets/CascadeDream/MiDreamworld.unity.
4. Для встраивания в существующую сцену доступен Prefabs/MiDreamworld.prefab.
   Он содержит свою камеру, AudioListener, свет и Volume. При встраивании
   оставьте одну активную камеру / AudioListener и согласуйте глобальное освещение.
5. Небо, туман и ambient-освещение хранятся в сцене. Полная сцена сохраняет
   их автоматически; перенос только prefab требует переноса Lighting Settings.
6. Для подключения к игровому управлению отключите Enable Demo Keys.
   DreamRunWorld.SetSpeed(float) задаёт целевую скорость,
   SetPaused(bool) управляет паузой, ResetRun() начинает забег заново.
   Root motion отключён: Ми остаётся на месте, окружение движется к камере.
7. MiRunner.prefab, CompanionOrb.prefab и BridgeGarden_*.prefab доступны отдельно.

Пакет содержит сцены, модели, материалы, карты, шейдеры, prefab и код исполнения.
Локальная очередь авторской сборки в пакет не включена.
Старая сцена Assets/CascadeSunset/SunsetBridge.unity сохранена отдельно.

ГРАНИЦЫ ГОТОВНОСТИ
Это отдельная рабочая сцена окружения и бега для дальнейшей интеграции.
Игровое поле, меню, музыка, задания и сбор предметов сюда пока не подключены.
Пульсация сферы настроена по BPM; анализ или синхронизация с аудиотреком не подключены.
Сфера — визуальный спутник, а не несколько собираемых объектов на пути.
Волосы и одежда используют существующий скелет; отдельная симуляция ткани не добавлена.
Производительность на телефоне не измерялась. Перед мобильным релизом нужны
проверка на целевых устройствах, подбор LOD и оптимизация исходной модели Ми (100К треугольников).
