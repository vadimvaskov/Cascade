# Проверка множителя всех восьми треков

Исправления находятся в `Updates/V3`. Сборка 1.0 (14) загружена в Apple; актуальный статус — [TestFlight](../../TestFlight.md).

## Реальная попытка с iPhone

Журнал Static Rocker прочитан с подключённого устройства. C# `Rhythm.Evaluate` точно воспроизвёл старый результат каждого из 65 принятых касаний: 23 hit, 40 miss, 2 excluded; лучшая серия 2, максимум ×1. Те же временные метки после исправления: 62 hit, 3 miss, лучшая серия 39, максимум ×10. Калибровка +142 мс сохранена. Это воспроизведение журнала, не новая игра на исправленной версии телефона.

## Карты и аудио

- Уровни 1, 2 и 8 проверены и сохранены побайтово. Для уровня 8 дефект в независимом аудиотесте не воспроизведён; без его журнала нельзя утверждать, что пользовательская проблема закрыта на телефоне.
- Phantom Limb и Ethereal Flight: сохранена рабочая басовая сетка, добавлена слышимая перкуссия. Близкие атаки в пределах 160 мс объединены центром окна; различимые чередующиеся пульсы остаются отдельными целями.
- Static Rocker: переход с ошибочной сетки около 91 BPM на ударные около 136 BPM, с поддержанными повторяющимися басовыми пульсами.
- Wasted Potential: восстановлены пропущенные чередующиеся доли, 146 BPM вместо половинной сетки 73 BPM.
- Liquid Nitrogen: учтены PCM-атаки баса вместе с перкуссией; исключаются только края карты и тихие участки длиной от секунды, а не отдельные слабые басовые удары.
- Правила множителя, окно конфигурации ±120 мс, калибровка и бонус 6/4 не изменены. При близких соседних долях прежнее ограничение окна до 45% интервала продолжает действовать.
- Все восемь WAV, их SHA-256 и длительность 90 с сохранены. Исходный проект вне Updates/V3 не менялся.

## Проверки

Генератор использует PCM RMS с причинными фильтрами. Отдельный FFT-анализатор извлекает последовательности ударов для настоящего C# `Rhythm.Evaluate`; это не касания, скопированные из точек проверяемой карты. Таблица показывает последовательность high_flux.

| Уровень | Трек | Попадания до → после | Макс. после |
|---|---|---:|---:|
| 1 | Disco Dancer | 182 → 182 | ×10 |
| 2 | Neon Overdrive | 122 → 122 | ×10 |
| 3 | Phantom Limb | 87 → 178 | ×10 |
| 4 | Static Rocker | 62 → 169 | ×10 |
| 5 | Ethereal Flight | 107 → 181 | ×10 |
| 6 | Wasted Potential | 107 → 212 | ×10 |
| 7 | Liquid Nitrogen | 204 → 239 | ×10 |
| 8 | Неоновый симфоний | 147 → 147 | ×10 |

Отдельно проверены басовая последовательность (падение допускается максимум на одно попадание), эквивалентность сохранённой калибровки на общих оцениваемых событиях, отрицательные смещённые касания, ×2 на третьем попадании, ×10 на 27-м, ограничение ×10 и повторное касание одной доли.

Unity 6000.6.8f1: `CascadeV3Checks`, `CascadeBonusChecks`, Play Mode `CascadeShortTrackChecks.RunRuntime` прошли. Все восемь запусков через меню, размещение, очки, HUD ×2/×10, длительность и результат на 1:30 — PASS. Проверка HUD на точках карты подтверждает подключение ресурсов, а не акустическое совпадение.

Артефакты: `audio-audit.json`, `independent-events.json`, `rhythm-regression.json`, `device-replay.json`, `unity-runtime.txt`, исходные PCM/FFT CSV и резервные карты в `before/`.

## Повторный запуск

```sh
clang++ -O2 -std=c++17 Tools/Audio/pcm_attacks.cpp -o /private/tmp/cascade-pcm-attacks
clang++ -O2 -std=c++17 Tools/Audio/onsets.cpp -o /private/tmp/cascade-v3-onsets
python3 Tools/Audio/repair_all_tracks.py # кандидаты и отчёт без публикации
python3 Tools/Audio/repair_all_tracks.py --write # обновление карт
dotnet run --project Tools/RhythmAudit -- .
```

Генератор не читает касания и калибровку. Все карты остаются предварительными, `verified=false`. Финальная слуховая проверка всех треков, новая попытка на физическом iPhone и выпуск новой сборки ещё нужны. Не запускать старые `analyze_v3.py`/`short_tracks.py --write` поверх исправлений: они восстанавливают старые карты.
