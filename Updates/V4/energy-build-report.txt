В этот отчёт входят только правки энергии и экспорта.
Спрайты .meta, URP, QualitySettings, GameSession, Conductor, Anim, BoardView здесь не перечислены — их в этом проходе не меняли.


1. Экспорт Unity

Файл: Assets/Cascade/Editor/CascadeV4Build.cs

Раньше всегда шла Development-сборка (профайлер, отладчик, радио Unity).
Теперь по умолчанию Release: development = false, BuildOptions.None.

Development включается только флагом командной строки:
  -cascadeDevelopment

Зачем: Energy Log показывал Overhead, сеть и фон из-за Player Connection, а не из-за игры.


2. Питание и кадры

Файл: Assets/Cascade/Scripts/App/CascadeApp.cs

- Application.runInBackground = false (раньше true)
- UseIdlePower(): 30 FPS, Screen.sleepTimeout = SystemSetting, AudioListener.pause = true
- UsePlayPower(): 60 FPS, NeverSleep, AudioListener.pause = false

Когда что:
- старт приложения, меню, карта, настройки — idle
- старт уровня и продолжение с паузы — play
- пауза уровня и сворачивание приложения — idle

DSP-буфер 256 не трогали: это задержка звука для ритма.


3. Игровой экран

Файл: Assets/Cascade/Scripts/UI/GameScreen.cs

- Begin / Resume вызывают UsePlayPower
- Pause вызывает UseIdlePower
- RhythmBar.Render вызывается, только если диаграмма включена
- убраны тени текста HUD (имя, трек, множитель, цель, оценка, тайминг, отсчёт)


4. Сцена героя

Файл: Assets/Cascade/Scripts/UI/HeroStrip.cs

- полос света 4 вместо 7
- позиция героя, сферы, swirl, цвет и масштаб пишутся, только если значение изменилось


5. Меню и карта

- MainMenuScreen: убраны тени имени игрока и названия главы
- WorldMapScreen: убрана тень заголовка карты

У Image raycast и так был выключен в UiKit.Img, это не меняли.


6. Телеметрия

- ProjectSettings/ProjectSettings.asset: submitAnalytics 1 → 0
- ProjectSettings/UnityConnectSettings.asset: Insights m_EngineDiagnosticsEnabled 1 → 0

В CascadeV4Build нельзя выставить PlayerSettings.submitAnalytics: в Unity 6000.6 этого свойства нет, сборка из-за этого один раз упала. Флаг оставлен только в ассете.


7. Что не делали

- геолокацию и сеть в игровом коде не добавляли и не искали: запросов нет
- FPS уровня не снижали ниже 60
- DSP-буфер не увеличивали
- пакеты physics/XR/webrequest не вырезали (отложено)
- Bloom не включали


8. Как снять Energy Log после этих правок

Экспорт без -cascadeDevelopment, в Xcode схема Unity-iPhone, конфигурация Release, без подключённого Unity Profiler.

13. Этап 4. Разгрузка CPU (V4)

Файлы:
- Assets/Cascade/Scripts/UI/Anim.cs
- Assets/Cascade/Scripts/Audio/Conductor.cs
- Assets/Cascade/Scripts/UI/BoardView.cs
- Assets/Cascade/Scripts/UI/GameScreen.cs
- Assets/Cascade/Core/GameSession.cs

Anim: Update убран. Корутина идёт, только пока есть твины, и останавливается, когда список пуст.

Conductor: Update убран. SongTime считается при чтении. Событие PlaybackChanged на Play / Pause / Resume / Stop.

BoardView: Update убран. Клетки рисуются в Play / SyncAll. Пульс рамки — корутина FadePulse, пока alpha > 0.

GameScreen: Update заменён на корутину часов уровня; на паузе она останавливается. HUD (очки, множитель, звёзды) обновляется по GameSession.Changed, не каждый кадр.

HeroStrip и RhythmBar по-прежнему двигаются по времени трека, пока уровень идёт: это не очки, а движение по dspTime.
